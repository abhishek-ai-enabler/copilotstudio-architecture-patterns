# copilotstudio-architecture-patterns
copilotstudio-architecture-patterns

**[Browse the Copilot Studio architecture catalog](CATALOG.md)** — 49 individually documented patterns, mapped to their sources as of November 27, 2026.

Every entry includes a component architecture, a numbered technical sequence, a decision for architecture review, and a **Copilot Studio components** section that names the harness, components and Copilot Credits drivers. For a worked example, see [SAP acknowledgment matching: architecture](reference-architectures/sap-order-acknowledgments.md#architecture) and [technical flow](reference-architectures/sap-order-acknowledgments.md#technical-flow).

Start with [Microsoft reference architectures](CATALOG.md#microsoft-reference-architectures) or [solution ideas](CATALOG.md#microsoft-solution-ideas) for an end-to-end scenario. To make a design decision, compare the [four Fabric integration options](CATALOG.md#fabric-integration-options), [orchestration and handoff options](CATALOG.md#orchestration-and-handoff-options), or [reusable technical patterns](CATALOG.md#synthesized-technical-patterns).

Two shared guides support every entry:

- [Copilot Studio components](COMPONENTS.md): harnesses (standard, Microsoft Copilot and Customer Conversation), orchestrator, topics, hooks, knowledge, tools, workflows and nodes, triggers, skills, memory, child and connected agents, and a [component matrix](COMPONENTS.md#pattern-component-matrix) for all 49 entries.
- [Copilot Credits guidance](COPILOT-CREDITS.md): billing by harness, rates, Microsoft 365 Copilot inclusion, estimation, governance and a [credit profile](COPILOT-CREDITS.md#pattern-credit-profiles) for each entry.
